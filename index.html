HyperSense

Independent project, built end to end.
Live app (v1.1). Abstract submitted; manuscript in preparation.

An explainable machine learning screener for hypertension risk in West Africa. From non-invasive inputs (age, sex, residence, education, tobacco use, height and weight), the app returns a High or Low risk tier, a probability, a SHAP explanation of the factors behind it, and a preventive recommendation. It is a screening tool, not a diagnostic one. I built the data harmonisation, modelling, explainability and deployment, then tested whether the model holds up in Nigeria.

Model
XGBoost on Ghana DHS 2014 (7,844 adults), survey-weighted, labelled from measured blood pressure only. ROC-AUC about 0.79, with the threshold chosen on out-of-fold predictions to avoid test-set leakage.
Nigerian external validation
Applied unchanged to 4,089 Nigerian adults, AUC fell from 0.792 to 0.747 and specificity from 0.616 to 0.448, with marked overprediction.
Regional adaptation
Retraining on a pooled Ghana–Nigeria cohort (11,933 adults) gave AUC 0.803, sensitivity 0.759, specificity 0.698 and near-ideal calibration. Adding 12 clinical predictors improved discrimination only modestly.
Limitations
The deployed model is Ghana-trained; the Nigerian adaptation is not in the app yet. The design is cross-sectional, so it estimates current likelihood, not future events.

Potato Leaf Disease Inspector

Team project, TAG AI Engineering Bootcamp, Cohort 1 (Team Tuner, six members).
Live MVP, scoped to potato leaves.

A web app that reports whether an uploaded potato leaf shows early blight, late blight or is healthy, with a confidence score, a plain-language explanation and a recommendation. A three-class classifier always picks a class, even for a cup or a tomato leaf, so the team added a second model that first checks the image is a potato leaf and rejects it if not.

Two-stage design
A fine-tuned ResNet18 classifier sits behind a binary potato-or-not detector. CLIP prompts and embedding similarity were tried first and abandoned because they could not separate similar leaves.
Results
The classifier got all 323 held-out images right, with healthy recall tracked because only 152 of 2,152 images were healthy. The detector reached 97.01% on 234 held-out images, accepting 7 of 127 non-potato images.
Limitations
The dataset results do not guarantee performance on arbitrary photos. In external testing a mango leaf was wrongly accepted, so the UI asks for potato leaves only.

Kredt

Team project, TAG AI Engineering Bootcamp, Cohort 1 (five members).
Deployed prototype; decision support, not a lending system.

AI-assisted credit intelligence for loan application review, built on the idea that the AI investigates and the analyst decides. A LangGraph pipeline validates an application, retrieves relevant credit policy, runs financial analysis and a credit-risk model, and assembles a report that an analyst can inspect before recording their own assessment.

Evidence you can audit
Five financial metrics are returned with the calculation behind each, alongside policy findings, a risk score and band, document views and an audit-oriented view.
Risk model
HistGradientBoosting beat a logistic baseline on Home Credit data (ROC-AUC 0.648 against 0.639). This reflects that dataset only, not Kredt’s intended borrowers.
Engineering
FastAPI backend in Docker, deployed to Azure Container Apps through GitHub Actions, with the frontend on Vercel. Some components are mock implementations and no production claims are made.

Local Study Assistant

Team project, TAG AI Engineering Bootcamp, Cohort 1 (six members).
Runs locally; no hosted demo by design.

A study tool that answers questions from a student’s own course materials. PDFs and audio recordings are ingested, chunked, embedded and stored in ChromaDB, and a locally run Llama 3.2 3B answers using only the selected course’s content, with source references. No cloud model API is involved.

Local-first RAG
Whisper transcription, Nomic embeddings and the language model all run through local tooling, so the core workflow should work offline once models are downloaded.
Course-scoped retrieval
Retrieval is limited to one course at a time, which keeps other courses’ materials out of the answer. FastAPI backend, Next.js and TypeScript frontend.
